Komputer Windows ini berfungsi khusus sebagai:
👉 SERVER BACKEND WHATSAPP, MESIN NLP, DAN NGROK TUNNEL.

Bagian Frontend / Web Admin TIDAK dijalankan di komputer ini, melainkan
dijalankan secara terpisah oleh rekan/teman Anda di laptopnya atau di hosting.

--------------------------------------------------------------------------------
1. CARA MENJALANKAN SERVER BACKEND (MODE HIDDEN / LATAR BELAKANG)
--------------------------------------------------------------------------------

A. MENJALANKAN SECARA TERSEMBUNYI (HIDDEN / LATAR BELAKANG):
   - Klik dua kali file:
     👉 START_SAPA_BPS_HIDDEN.vbs
     (atau klik dua kali 👉 START_SAPA_BPS.bat)
   - Kedua layanan (Backend WhatsApp Port 80 & Ngrok Tunnel) akan langsung
     berjalan secara diam-diam di latar belakang Windows.
   - TIDAK ADA JENDELA CMD yang muncul atau mengganggu layar Anda!
   - Sebuah notifikasi Windows akan muncul di sudut kanan bawah memberitahu
     bahwa server telah aktif.

B. MEMERIKSA STATUS SERVER:
   - Klik dua kali file:
     👉 STATUS_SAPA_BPS.bat
   - Anda akan melihat ringkasan status Port 80, nomor WA yang terhubung,
     status tunnel Ngrok, serta tombol pintas membuka Web Admin.

C. MELIHAT LOG AKTIVITAS BOT SECARA REAL-TIME:
   - Klik dua kali file:
     👉 LIHAT_LOG_SAPA_BPS.bat
   - Layar monitor log akan menampilkan percakapan atau aktivitas bot WA.
   - Anda bisa menutup jendela log kapan saja dengan menekan Ctrl+C tanpa
     menghentikan bot di latar belakang.

D. MENGHENTIKAN SERVER (STOP):
   - Klik dua kali file:
     👉 STOP_SAPA_BPS.bat
   - Semua layanan backend WhatsApp dan tunnel ngrok akan dihentikan seketika.

E. MODE TERMINAL TERLIHAT (DEBUG MODE):
   - Jika Anda butuh melihat jendela CMD terbuka untuk pengecekan teknis:
     Jalankan via Command Prompt: START_SAPA_BPS.bat --visible

--------------------------------------------------------------------------------
2. DATA YANG PERLU DIBERIKAN KEPADA TEMAN ANDA (FRONTEND DEVELOPER)
--------------------------------------------------------------------------------

Agar frontend yang dikembangkan teman Anda di laptopnya (atau di hosting)
dapat terhubung dan berkomunikasi lancar dengan Backend WhatsApp Anda:

Kirimkan teks konfigurasi berikut ke teman Anda:

===================================================================
KONFIGURASI ENV UNTUK FRONTEND TEMAN:
-------------------------------------------------------------------
NEXT_PUBLIC_BACKEND_URL=https://footless-aptitude-caloric.ngrok-free.dev
BACKEND_URL=https://footless-aptitude-caloric.ngrok-free.dev
NEXT_PUBLIC_API_KEY=sapa_bps_secure_token_2026
-------------------------------------------------------------------

Teman Anda cukup meletakkan variabel di atas ke file `.env.local` 
di laptopnya atau di dashboard hostingnya (misal: Vercel / Netlify).
